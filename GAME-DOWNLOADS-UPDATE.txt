Revision 12 — Cloudflare Workers game downloads

For the existing Git-connected Worker:
1. Extract the files alongside the repository's package.json. If using the
   small repair ZIP, keep the existing src/, public/, and game ZIPs.
2. Check the Worker name in your Cloudflare dashboard. If it differs from
   gregory-sherris-portfolio, set name in wrangler.jsonc to the existing name.
3. Commit and push the extracted files. Use the repository root in Workers
   Builds and keep its deploy command as: npx wrangler deploy

Local verification (Node 22.12+ or 24):
  npm ci
  npm run deploy:check
  npm run test:downloads

The complete edition ships 16 MiB parts. The repair also works with the
previous complete ZIPs: the build splits them automatically. Each visitor
still downloads one original UpWeGoat.zip or RockPaperCity.zip. The Worker
script and the static assets must be deployed together.
