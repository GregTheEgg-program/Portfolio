Gregory Sherris portfolio — Cloudflare game downloads, v14

In the existing portfolio repository, extract this update next to package.json.
Keep the original game files already in public/downloads/ or public/downloads/parts/.
If you have a custom Cloudflare Worker name, retain it in wrangler.jsonc.
Commit and push the extracted files. Keep the deploy command: npx wrangler deploy

Surfing Poseidon: visitors get a single portable Windows ZIP (63.4 MiB).
Extract it and run SurfingPoseidon/Practise.exe. Its game files have not been modified.
The optional Unity build-debug folder marked DoNotShip was omitted.
Gamblers Never Quit: the DigiPen button is directly below the title on the
project card and in its details. Up We Goat and Rock, Paper, City each have
a smaller Windows installer and their original portable ZIP.

To add The Tower, use a ZIP of the packaged Windows game, not the Unreal source folder.
From the folder containing package.json run:
  npm run import:tower -- "path/to/TheTower.zip"
  npm run deploy:check
  npm run test:downloads
Commit cloudflare/tower-release.json and the generated public/downloads/parts/
files and push. You do not need to commit the large input ZIP. Once imported,
The Tower's card and details display the real ZIP's size and download button.

Every game is served through the portfolio itself. The Worker streams stored
pieces of at most 16 MiB as one file; the build also rejects any static asset
over 25 MiB. You do not need to publish your private game source repositories.
