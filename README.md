# Gregory Sherris — React Portfolio

A simple, responsive portfolio built with React and Vite, based on the supplied résumé. Includes a featured game engine project, experience, skills, education, contact links, a résumé download, and a small illustrative collision demo.

## Run locally

Install Node.js 22.12+ (or Node.js 20.19+), unzip the project, and open a terminal in this folder:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Edit

- `src/App.jsx`: profile details, experience, skills, and page content.
- `src/styles.css`: colors, layout, and responsive styles.
- `public/Gregory-Sherris-Resume.pdf`: replace this to update the résumé download.
- `index.html`: browser title and description.

The collision graphic is an illustration made for this portfolio, not a screenshot or build of the original game engine. Google Fonts are optional; system fonts are used when unavailable. No backend, account setup, or hosting service is required.
